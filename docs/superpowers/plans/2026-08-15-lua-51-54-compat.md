# Lua 5.1–5.4 Compat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `asyncsocket` and `luadap` build and pass the minimum test suite on Lua 5.1, 5.2, 5.3, and 5.4, with a thin in-repo compat layer and CI matrix.

**Architecture:** Add `native/common/lua_compat.{h,c}` that polyfills only the APIs we use. Rewrite `asyncsocket` to single-uservalue userdata (no `*uv` / `*iuservalue`). Attach evaluate/BP chunk envs via `ld_set_chunk_env` (`setfenv` on 5.1, `_ENV` upvalue on 5.2+). CMake selects Lua via `LUA_VERSION` / `LUA_ROOT` / FetchContent; default remains vendored 5.4.8. CI runs four version jobs.

**Tech Stack:** C11, CMake 3.16+, Lua 5.1–5.4 C API, existing Python DAP / asyncsocket tests, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-08-15-lua-51-54-compat-design.md`

## Global Constraints

- Versions: Lua 5.1 / 5.2 / 5.3 / 5.4 only (no LuaJIT)
- Compat: self-written `native/common/lua_compat.{h,c}` only (no Kepler/sol2 vendor)
- Userdata: single uservalue table on all versions
- Chunk env: 5.1 `setfenv`; 5.2+ `lua_setupvalue(chunk, 1)` for `_ENV`
- Default build: `3rd/lua-5.4.8`; other versions via `LUA_ROOT` or FetchContent (not committed)
- `main`/sol2: build only when `LUA_VERSION=5.4`
- Do not change DAP evaluate writeback semantics
- Do not modify `3rd/luasocket` compat
- English concise commits
- Default local build: `cmake --build build/msvc --target luadap` / `asyncsocket`

**Locked helpers:**

```c
/* lua_compat.h — after lua.h / lauxlib.h */
/* Provides on older Luas: LUA_OK, lua_absindex, lua_pushglobaltable,
 * lua_rawgetp/lua_rawsetp, luaL_setfuncs, luaL_tolstring,
 * luaL_checkinteger, lua_getuservalue, lua_setuservalue,
 * luaL_setmetatable (5.1). */

/* lua_debug.c */

 * After return, chunk remains; env is consumed (setfenv/setupvalue) or

```

**Discovered dependency (must polyfill, used by asyncsocket today):** `luaL_setmetatable` (5.2+).

**Files:**

**Interfaces:**
- Produces: `lua_compat.h` API surface listed above; on 5.4 all macros no-op / passthrough
- Consumes: system/Lua headers from current `liblua`

- [ ] **Step 1: Add `lua_compat.h`**

```c
#ifndef LUA_COMPAT_H
#define LUA_COMPAT_H

#include <lua.h>
#include <lauxlib.h>

#if LUA_VERSION_NUM < 501 || LUA_VERSION_NUM > 504
#error "lua_compat: unsupported Lua version"
#endif

#if LUA_VERSION_NUM == 501
#ifndef LUA_OK
#define LUA_OK 0
#endif
#define lua_pushglobaltable(L) lua_pushvalue((L), LUA_GLOBALSINDEX)
#define luaL_checkinteger(L, n) ((lua_Integer)luaL_checkint((L), (n)))
/* Declarations — implemented in lua_compat.c */
int lua_absindex(lua_State *L, int i);
int lua_rawgetp(lua_State *L, int idx, const void *p);
void lua_rawsetp(lua_State *L, int idx, const void *p);
void luaL_setfuncs(lua_State *L, const luaL_Reg *l, int nup);
const char *luaL_tolstring(lua_State *L, int idx, size_t *len);
void luaL_setmetatable(lua_State *L, const char *tname);
/* uservalue ↔ fenv (table only) */
#define lua_getuservalue(L, i) (lua_getfenv((L), (i)))
#define lua_setuservalue(L, i) \
  (luaL_checktype((L), -1, LUA_TTABLE), lua_setfenv((L), (i)))
#endif /* 501 */

#if LUA_VERSION_NUM == 502
/* luaL_tolstring exists in 5.2; rawgetp exists. Nothing required unless
 * return-type wrappers needed — keep empty if build is clean. */
#endif

#endif /* LUA_COMPAT_H */
```

Adjust `#if` blocks so 5.2 gets `luaL_tolstring` only if missing (it is not). Prefer `#ifndef` guards around every macro/declaration so double-include is safe.

- [ ] **Step 2: Implement `lua_compat.c` for 5.1**

Mirror luasocket / Kepler minimal forms for: `lua_absindex`, `lua_rawgetp`, `lua_rawsetp`, `luaL_setfuncs`, `luaL_tolstring`, `luaL_setmetatable`. Wrap bodies in `#if LUA_VERSION_NUM == 501` (and `#if LUA_VERSION_NUM <= 502` only if a symbol is actually missing). On 5.4 the `.c` file may compile to empty translation unit — that is OK.

- [ ] **Step 3: Wire CMake**

In `native/asyncsocket/CMakeLists.txt` and `native/luadap/CMakeLists.txt`:
- `target_sources(... ${CMAKE_SOURCE_DIR}/native/common/lua_compat.c)`
- `target_include_directories(... PRIVATE ${CMAKE_SOURCE_DIR}/native/common)`

- [ ] **Step 4: Include compat after lua headers**

In `asyncsocket.c` and every `luadap` `.c` that includes `lua.h`:

```c
#include <lua.h>
#include <lauxlib.h>

```

Do **not** change userdata APIs yet.

- Produces: same Lua API; no `lua_newuserdatauv` / `lua_*iuservalue` in this file

- [ ] **Step 1: Replace helpers**

Change `set_callback` / `push_conn` / `l_listen` / dispatch paths:

```c
static void set_callback(lua_State *L, int ud_idx, const char *name) {
    luaL_checktype(L, 2, LUA_TFUNCTION);
    lua_getuservalue(L, ud_idx);
    lua_pushvalue(L, 2);
    lua_setfield(L, -2, name);
    lua_pop(L, 1);
}

static void push_conn(lua_State *L, int conn_id) {
    as_conn_ud *ud = (as_conn_ud *)lua_newuserdata(L, sizeof(as_conn_ud));
    ud->conn_id = conn_id;
    lua_newtable(L);
    lua_setuservalue(L, -2);
    luaL_setmetatable(L, AS_CONN_MT);
    registry_get_conns(L);
    lua_pushvalue(L, -2);
    lua_rawseti(L, -2, conn_id);
    lua_pop(L, 1);
}
```

Same pattern for `l_listen` server ud. Replace every `lua_getiuservalue(L, x, 1)` with `lua_getuservalue(L, x)`.

### Task 3: `ld_set_chunk_env` for evaluate + BP condition

**Files:**
- Modify: `native/luadap/lua_debug.c`
- Test: `script/test/test_dap_evaluate.py`, `script/test/test_dap_condition.py` (5.4)

**Interfaces:**
- Produces: `static void ld_set_chunk_env(lua_State *L, int chunk_idx, int env_idx);`
- Consumes: `push_frame_env`; existing evaluate / BP load paths

- [ ] **Step 1: Add helper**

```c
static void ld_set_chunk_env(lua_State *L, int chunk_idx, int env_idx) {
    chunk_idx = lua_absindex(L, chunk_idx);
    env_idx = lua_absindex(L, env_idx);
#if LUA_VERSION_NUM == 501
    lua_pushvalue(L, env_idx);
    lua_setfenv(L, chunk_idx);
    /* setfenv consumes the env copy from stack top */
#else
    lua_pushvalue(L, env_idx);
    if (lua_setupvalue(L, chunk_idx, 1) == NULL)
        lua_pop(L, 1);
#endif
}
```

Verify 5.1 `lua_setfenv` stack effect against Lua 5.1 manual (consumes value at top). Adjust push/pop so call sites leave stack consistent with today (chunk at expected index, env table still available if needed then popped via `lua_settop`).

- [ ] **Step 2: Call from BP + evaluate**

Replace both:

```c
lua_pushvalue(L, env);
if (lua_setupvalue(L, -2, 1) == NULL)
    lua_pop(L, 1);
```

with:

```c
ld_set_chunk_env(L, -1 /* chunk after load */, env);
```

Use absolute indices if relative indices are ambiguous after `loadstring`.

```yaml
name: lua-compat-matrix

    runs-on: windows-latest
    strategy:
      fail-fast: false
      matrix:
        lua: ["5.1", "5.2", "5.3", "5.4"]
    steps:
      - uses: actions/checkout@v4
      - uses: ilammy/msvc-dev-cmd@v1
      - name: Configure
        run: cmake -S . -B build -G "Ninja" -DLUA_VERSION=${{ matrix.lua }} -DCMAKE_BUILD_TYPE=Release
      - name: Build
        run: cmake --build build --target lua asyncsocket luadap
      - name: Tests
        shell: pwsh
        run: |
          $env:PATH = "$pwd/bin;$env:PATH"
          python script/test/test_asyncsocket_smoke.py
          python script/test/test_dap_luadap_handshake.py
          python script/test/test_dap_evaluate.py
          python script/test/test_dap_condition.py
```

Adjust generator (`Ninja` vs VS) to match repo practice; ensure test scripts find `lua.exe` / DLLs under `bin/` (existing `find_lua()` helpers). If handshake test name differs, use the same “luadap-only” handshake test already in `script/test/`.
