# Lua 5.1.5 / 5.2.4 / 5.3.6 CMake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add standalone `CMakeLists.txt` for vendored Lua 5.1.5, 5.2.4, and 5.3.6 that build static `liblua`, `lua`, and `luac` from official Makefile source lists.

**Architecture:** Each Lua tree gets its own root `CMakeLists.txt`. `liblua` is a STATIC library from CORE+LIB sources; `lua`/`luac` are executables that link `liblua` (5.1 `luac` also compiles `print.c`). Platform defines and system libs are applied via CMake `if(WIN32/APPLE/UNIX)` blocks matching the approved design.

**Tech Stack:** CMake ≥ 3.20, C90 (5.1) / C99 (5.2–5.3), official Lua sources under `3rd/lua-5.x.y/src/`

## Global Constraints

- `cmake_minimum_required(VERSION 3.20)`
- Static library only; no `LUA_BUILD_AS_DLL`, no shared `liblua`
- Do not modify `3rd/lua-5.4.8/CMakeLists.txt` or root/`native` CMake
- No readline; no install/pkg-config rules
- Headers live in `src/` (not `inc/`)
- Spec: `docs/superpowers/specs/2026-08-15-lua-515-536-cmake-design.md`

## File Map

| File | Responsibility |
|------|----------------|
| `3rd/lua-5.1.5/CMakeLists.txt` | Build Lua 5.1.5 liblua/lua/luac (+ print.c) |
| `3rd/lua-5.2.4/CMakeLists.txt` | Build Lua 5.2.4 with `LUA_COMPAT_ALL` |
| `3rd/lua-5.3.6/CMakeLists.txt` | Build Lua 5.3.6 with `LUA_COMPAT_5_2` + lutf8lib |

### Task 1: Lua 5.1.5 CMakeLists

**Files:**
- Create: `3rd/lua-5.1.5/CMakeLists.txt`
- Test: configure + build under `3rd/lua-5.1.5/build`

**Interfaces:**
- Consumes: none
- Produces: targets `liblua` (STATIC), `lua`, `luac`

- [ ] **Step 1: Create `3rd/lua-5.1.5/CMakeLists.txt`**

Write the full file:

```cmake
cmake_minimum_required(VERSION 3.20)
project(lua-5.1.5 C)

set(CMAKE_C_STANDARD 90)
set(CMAKE_C_STANDARD_REQUIRED ON)

set(LUA_CORE_SRC
  src/lapi.c src/lcode.c src/ldebug.c src/ldo.c src/ldump.c
  src/lfunc.c src/lgc.c src/llex.c src/lmem.c src/lobject.c
  src/lopcodes.c src/lparser.c src/lstate.c src/lstring.c src/ltable.c
  src/ltm.c src/lundump.c src/lvm.c src/lzio.c
)

set(LUA_LIB_SRC
  src/lauxlib.c src/lbaselib.c src/ldblib.c src/liolib.c
  src/lmathlib.c src/loslib.c src/ltablib.c src/lstrlib.c
  src/loadlib.c src/linit.c
)

add_library(liblua STATIC ${LUA_CORE_SRC} ${LUA_LIB_SRC})
target_include_directories(liblua PUBLIC ${CMAKE_CURRENT_SOURCE_DIR}/src)
set_property(TARGET liblua PROPERTY FOLDER "lua")

add_executable(lua src/lua.c)
target_link_libraries(lua PRIVATE liblua)
set_property(TARGET lua PROPERTY FOLDER "lua")

add_executable(luac src/luac.c src/print.c)
target_link_libraries(luac PRIVATE liblua)
set_property(TARGET luac PROPERTY FOLDER "lua")

if(NOT WIN32)
  target_compile_options(liblua PRIVATE -fPIC)
endif()

if(WIN32)
  # no LUA_USE_* for default Windows static build
elseif(APPLE)
  target_compile_definitions(liblua PUBLIC LUA_USE_LINUX)
  target_link_libraries(liblua PUBLIC m)
elseif(CMAKE_SYSTEM_NAME STREQUAL "Linux")
  target_compile_definitions(liblua PUBLIC LUA_USE_LINUX)
  target_link_libraries(liblua PUBLIC m dl)
else()
  target_compile_definitions(liblua PUBLIC LUA_USE_POSIX)
  target_link_libraries(liblua PUBLIC m)
endif()
```

- [ ] **Step 2: Configure and build**

Run from repo root (PowerShell):

```powershell
cmake -S 3rd/lua-5.1.5 -B 3rd/lua-5.1.5/build
cmake --build 3rd/lua-5.1.5/build
```

Expected: build succeeds; artifacts include `liblua` (e.g. `liblua.lib` / `libliblua.a` depending on generator) plus `lua` and `luac` executables under the build tree.

- [ ] **Step 3: Smoke-run interpreter**

```powershell
& (Get-ChildItem -Recurse -Path 3rd/lua-5.1.5/build -Filter lua.exe | Select-Object -First 1).FullName -e "print(_VERSION)"
```

On Unix:

```bash
$(find 3rd/lua-5.1.5/build -name lua -type f | head -1) -e 'print(_VERSION)'
```

Expected: prints `Lua 5.1`

- [ ] **Step 4: Commit**

```bash
git add 3rd/lua-5.1.5/CMakeLists.txt
git commit -m "build: add CMake for Lua 5.1.5"
```
