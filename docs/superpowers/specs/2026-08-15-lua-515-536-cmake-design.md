# Lua 5.1.5 / 5.2.4 / 5.3.6 CMake 编译脚本设计

**日期：** 2026-08-15  
**状态：** 已批准待实现  
**范围：** 为 `3rd/lua-5.1.5`、`3rd/lua-5.2.4`、`3rd/lua-5.3.6` 各新增根目录 `CMakeLists.txt`，按官方 `src/Makefile` 构建 `liblua` / `lua` / `luac`。

**前置：**
- 仓库已有 `3rd/lua-5.4.8/CMakeLists.txt`（GLOB + 可执行文件内嵌 core 源）
- 三份旧版 Lua 源码树已 vendoring，头文件均在 `src/`（无 5.4 的 `inc/` 拆分）
- 本设计**不**改动根工程 `LUA_VERSION` / FetchContent / 兼容层接线

## 目标

1. 各版本可独立 `cmake -B build && cmake --build build` 产出静态库与解释器/编译器。  
2. 源文件列表与官方 Makefile 的 `CORE_O` / `LIB_O` / `LUA_O` / `LUAC_O` 一致。  
3. `lua` / `luac` **链接** `liblua`，不重复编译 core。  
4. 默认兼容宏与 Makefile 一致。

## 已锁定决策

| 决策 | 选择 |
|------|------|
| 风格 | 方案 B：显式源列表 + 链接 liblua（非对齐 5.4.8 GLOB） |
| 库形态 | 仅静态库 `liblua`；不做默认 DLL / `LUA_BUILD_AS_DLL` |
| 5.4.8 | 本次不改 |
| 根工程 | 本次不接线 |
| readline | 不链接（避免可选依赖） |

## 目标与源文件

每个目录 `project(lua-5.x.y)`，`cmake_minimum_required(VERSION 3.20)`，`include_directories(src)`，目标 `FOLDER "lua"`。

### 公共目标

| 目标 | 类型 | 组成 |
|------|------|------|
| `liblua` | STATIC | CORE + LIB |
| `lua` | executable | `src/lua.c` + link `liblua` |
| `luac` | executable | `src/luac.c`（5.1 另加 `src/print.c`）+ link `liblua` |

### 5.1.5

- **CORE：** `lapi` `lcode` `ldebug` `ldo` `ldump` `lfunc` `lgc` `llex` `lmem` `lobject` `lopcodes` `lparser` `lstate` `lstring` `ltable` `ltm` `lundump` `lvm` `lzio`
- **LIB：** `lauxlib` `lbaselib` `ldblib` `liolib` `lmathlib` `loslib` `ltablib` `lstrlib` `loadlib` `linit`
- **无：** `lctype` `lbitlib` `lcorolib` `lutf8lib`
- **C 标准：** C90（与现有 5.4 CMake 习惯一致）
- **兼容宏：** 无

### 5.2.4

- **CORE：** 5.1 CORE + `lctype`
- **LIB：** `lauxlib` `lbaselib` `lbitlib` `lcorolib` `ldblib` `liolib` `lmathlib` `loslib` `lstrlib` `ltablib` `loadlib` `linit`
- **兼容宏：** `LUA_COMPAT_ALL`
- **C 标准：** C99

### 5.3.6

- **CORE：** 同 5.2
- **LIB：** 同 5.2 + `lutf8lib`
- **兼容宏：** `LUA_COMPAT_5_2`
- **C 标准：** C99（贴近 Makefile `gcc -std=gnu99`）

## 平台宏与链接

默认静态库；平台宏由 CMake 检测：

| 平台 | 宏 | 链接库 |
|------|-----|--------|
| Windows | 不加 `LUA_USE_*` | 无额外（MSVC）；MinGW 视需要 `m` |
| Linux | `LUA_USE_LINUX` | `m` `dl` |
| macOS | 5.2+：`LUA_USE_MACOSX`；5.1：`LUA_USE_LINUX` 或 POSIX 等价（与官方 macosx 目标一致即可） | `m` |
| 其它 Unix | `LUA_USE_POSIX` | `m` |

非 Windows 可加 `-fPIC`（便于日后被共享库链接）。

